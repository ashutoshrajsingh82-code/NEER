# NEER Frontend

Minimal Next.js (App Router) frontend for **NEER — Neural Embedding based
Estimation and Reconstruction** (SIH26066, MoES / INCOIS).

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Visit http://localhost:3000 — it displays the project name, full name,
problem ID, and organization. No dashboard functionality yet (Phase 01
scaffold only).
