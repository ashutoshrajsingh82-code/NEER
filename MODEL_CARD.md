## Training data

- **Source(s):** TBD. Real INCOIS/ARGO data is not yet integrated. All
  pipeline development to date runs on the synthetic demo dataset
  (`data/demo/`, generated by `scripts/create_demo_data.py`), which is
  **not** observational data and carries a `DEMO_SYNTHETIC` marker
  through every stage into the tensors and their metadata.
- **Domain:** 5°N-30°N, 45°E-105°E at 0.25° (101 x 241), 15 depth levels
  from 0 to 1000 m, monthly cadence.
- **Preprocessing:** implemented in `src/data/preprocessing` (Phase 07).
  Coordinate normalization, temporal alignment, spatial alignment onto
  the target grid, missing-value handling, masking, feature construction
  and normalization, assembled into `(time, channel, lat, lon)` inputs
  and `(time, depth, lat, lon)` targets with accompanying validity masks.
  Every run writes a metadata record of its configuration, fitted state
  and split.
- **Input features (Phase 08):** exactly eleven channels, in the fixed
  order defined by `src/data/preprocessing/channels.py` —
  `sst`, `sss`, `sla` (raw surface fields); `u_current`, `v_current`,
  `u_wind`, `v_wind` (raw vector components, not derived speed); and
  `time_sin`, `time_cos`, `lat_norm`, `lon_norm` (cyclic time and
  normalized position, built by `FeatureBuilder`). `TensorAssembler`
  uses this order by default, so it cannot drift between training and
  inference. Covered by `tests/test_channels.py`.
- **Split:** chronological — train, then validation, then test — never
  random, because ocean fields are strongly autocorrelated in time.
  Default 70/15/15 by timestep.
- **Leakage control:** steps that learn (the gap-filling climatology and
  the normalization statistics) are fitted on the training period only,
  checked at runtime by `assert_fit_window`; after the split each period
  is transformed separately so no step can interpolate across a boundary.
  Verified in `tests/test_preprocessing_leakage.py`.
- **Missing data:** substantial and structural, not incidental. In the
  demo dataset roughly 13% of ocean surface cells and 55% of ocean
  subsurface cells are unobserved at any given timestep. Gaps are filled
  so the tensors are finite, and the fill is recorded: only ~24% of
  target cells are marked observed. **Any loss or metric must be masked** —
  scoring against filled values measures the filler, not the model.
